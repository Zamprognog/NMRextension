The yago4.5 LP dataset is generated from yago facts, by selecting all triples that:
- include a yago:_ or schema:_ property
- include entities that are involved in at least 10 of the aforementioned triples

This is generated by the follwoing SPARQL query:

```angular2html
PREFIX yago: <http://yago-knowledge.org/resource/>
PREFIX schema: <http://schema.org/>

SELECT ?s ?p ?o
WHERE {
  {
    SELECT ?s ?p ?o
    WHERE {
      ?s ?p ?o .
      FILTER(STRSTARTS(STR(?p), STR(yago:)) || STRSTARTS(STR(?p), STR(schema:)))
    }
  }

  {
    SELECT ?s (COUNT(?s) AS ?sCount)
    WHERE {
      ?s ?p ?o .
      FILTER(STRSTARTS(STR(?p), STR(yago:)) || STRSTARTS(STR(?p), STR(schema:)))
      FILTER(!isLiteral(?o))
    }
    GROUP BY ?s
    HAVING (?sCount >= 10)
  }

  {
    SELECT ?p (COUNT(?p) AS ?pCount)
    WHERE {
      ?s ?p ?o .
      FILTER(STRSTARTS(STR(?p), STR(yago:)) || STRSTARTS(STR(?p), STR(schema:)))
      FILTER(!isLiteral(?o))
    }
    GROUP BY ?p
    HAVING (?pCount >= 10)
  }
}
```
